# RAG Knowledge Assistant

Переиспользуемый конвейер для построения RAG-ассистентов под любые базы знаний и роли ответа. Демонстрационная инстанция — голосовая энциклопедия динозавров для ребёнка.

## Контекст и цель

**Зачем:** построить универсальный конвейер, который можно быстро адаптировать под разные домены (энциклопедии, инструкции, FAQ) без переписывания логики с нуля.

**Проблема:** большинство RAG-реализаций заточены под одну конкретную задачу. Перенос на новый домен требует перестройки промптов, эмбеддингов и логики поиска.

**Решение:** модульная архитектура с чёткими интерфейсами между компонентами: загрузка знаний → эмбеддинг → поиск → генерация ответа → голосовой вывод.

## Архитектура конвейера

    [PDF/текст] → [Загрузка в локальное админ-приложение] → [Эмбеддинг] → [Vector DB]
                                                                              ↓
    [Голосовой запрос] → [STT] → [RAG-поиск] → [LLM с ролью] → [TTS] → [Ответ]

### Ключевые компоненты (текущий стек)

1. **Загрузка знаний:** локальное админ-приложение на CustomTkinter для двойного клика по PDF
2. **Эмбеддинг:** YandexGPT embeddings с настраиваемым chunk_size
3. **Vector DB:** Qdrant для поиска по косинусному сходству
4. **RAG-поиск:** Top-K retrieval с reranking по relevance score
5. **Роль ответа:** системный промпт, задающий тон и стиль (дружелюбный для ребёнка, формальный для бизнеса)
6. **Голосовой ввод/вывод:** SpeechKit (STT/TTS)

## Метрики качества поиска

Тестирование на датасете из 50 вопросов по энциклопедии динозавров (снято на текущем стеке до остановки демо):

| Метрика | Значение | Описание |
|---------|----------|----------|
| **Accuracy@1** | 78% | Правильный ответ в первом результате поиска |
| **Accuracy@3** | 92% | Правильный ответ в топ-3 результатах |
| **Avg. retrieval time** | 1.2s | Среднее время поиска по 500 документам |
| **Hallucination rate** | 8% | Ответы, не основанные на базе знаний |

## Статус проекта

**Сейчас:** код и архитектура полностью доступны в репозитории, но публичное демо недоступно. Проект был развёрнут на Яндекс Cloud; после выхода из строя data центров, проект приостановил свою работу.

**План:** миграция на Gigachat (эмбеддинги и генерация ответов) — на этапе планирования, миграция ещё не выполнена. Поэтому в коде и в инструкциях ниже фигурирует Яндекс-стек: это текущее состояние репозитория, а не желаемое.

**MAX-бот:** маршрутизация команд для голосового управления умным домом написана и протестирована офлайн, в активной разработке.

## Что моё, что AI

### Моё

- Продуктовая постановка: голосовая энциклопедия для сына + переиспользуемый конвейер
- Требования к ролям и голосам (дружелюбный тон для ребёнка)
- База знаний: кураторство контента про динозавров
- Приёмочные сценарии и метрики качества поиска (Accuracy@1/@3, hallucination rate)
- Дизайн локального админ-приложения для загрузки PDF
- Маршрутизация команд для MAX-бота

### Код

Написан AI-ассистентом по моим спецификациям. Я формулировала требования, тестировала на реальных данных, валидировала результаты и итерировала промпты.

## Локальный запуск (текущий стек — Яндекс)

    git clone https://github.com/Kris-Tsilik/rag-knowledge-assistant.git
    cd rag-knowledge-assistant
    pip install -r requirements.txt

    # Запустить админ-приложение для загрузки PDF
    python admin_app.py

    # Запустить голосового ассистента
    python main.py

**Требования:** Python 3.9+, микрофон, колонки, API-ключ YandexGPT / SpeechKit.
